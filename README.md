# RT-Thread + MCXA346 智能电机控制实验平台

2026 RT-Thread 嵌入式大赛参赛仓库整理版。硬件为 FRDM-MCXA346、
AS5600、SimpleFOC Mini、7对极2804电机；12V母线，无电流采样。
控制在MCU本地运行，上位机以串口CLI调参，网页用于监控与固定时序演示。

## 目录

```text
app/              固件：RTT移植、编码器、PWM、速度/位置控制、NN、串口

debug/            唯一本地构建目录，Git忽略，不随仓库提交
```

## 开始

1. 阅读 [构建与复现](docs/BUILD.md)，配置本地SDK/工具链路径。
2. 阅读 [接线](docs/HARDWARE.md)。
3. CLI：在仓库根目录 `conda activate py310` 后运行
   `python tools/control_cli.py auto`。USB串口编号自动按适配器身份选择。
4. 离线测试：`python tools/run_host_tests.py`。此操作不连接硬件。
5. 提交进度见 [材料清单](docs/SUBMISSION.md)。

参赛项目说明见 [PROJECT_INTRO.md](docs/PROJECT_INTRO.md)，包含实物连接图和网页上位机截图。
网页监测启动：`python tools/web_monitor.py`，在浏览器打开终端显示的本地地址。
网页支持“电机校准”“一键演示”和“停止”；连接后可直接在网页完成校准与演示。
手动控制可下发±1000 RPM整数转速（正负值选方向，0为停止），
以及相对当前位置或相对校准零点的角度目标；位置目标不自动取模。
速度与位置各自保留一组参数，切换时应用相应参数，
连续位置命令保持平滑轨迹，不反复停机。
“应用参数”和“应用NN”均弹窗二次确认；取消不下发修改，
确认后先停机、按ACK确认应用，不自动恢复运行。
参数包括速度Kp/Ki、位置Kp、位置限速、轨迹时长及限压。
NN开关使用现有G2混合控制/G0传统控制，支持0至1融合系数；
一键演示保留本次网页已确认的NN选择，未设置时仍使用传统基线。
网页显示最近成功ACK的设置，不将会话初值伪装成MCU参数读回；
新连接的NN显示“未下发”。当前网页参数组在服务内存中保存。
手动运行由后台共用原串口持续发送H0，直到点击停止、断开串口或下发新目标；
不依赖网页心跳、页面刷新率或标签页是否在前台。固件原有1秒通信看门狗不变。
演示需新固件的只读 `c0` 位置查询与有效校准，校准由用户点击启动。
按下后等待1秒，以60 RPM运行3秒，停1秒；再以停机后位置为起点，
依次下发+120°、+240°、+360°，间隔0.5秒；最后额外保持1秒后停机。
位置段使用实板筛选的平滑轨迹与独立增益，演示后恢复原参数。

CLI单独复现这组位置配置（使用已有有效校准，无需重复校准）：

```text
stop
nn off
voltage 1.0
kp 0.040
ki 0.650
poskp 15
posmax 90
posmove 500
position 120
```

`position` 是相对校准零点的绝对角度，单位度，并非相对当前位置增量。
`posmove 500` 开启最短500 ms的连续位置轨迹；较大行程按速度、加速度约束延长。
`posmove 0` 可在停机时恢复原位置路径；固件上电默认仍为原路径。

## 已验证与未验证

已具备编码器读取、速度/位置控制、传统控制基线、轻量NN训练和固件推理通路。
最新冻结的25ms P项目标平滑对照覆盖60段、三轮、十种低速切换：
整段RMSE均值下降5.83%，首秒下降11.77%。
这是**传统控制改进，不是NN收益**；NN未获得稳定超过线性预测的优势。
2026-10-26位置实板对照：同一次校准、两轮正反顺序，NN关闭。
平滑轨迹配合新增益后，10°往返末段平均绝对误差从2.34°降至0.28°，
末段角度摆幅均值从2.45°降至0.064°；三段120°后末段误差从1.00°降至0.13°。
完整网页演示已跑通并确认停机。这也是传统控制改进，不是NN收益；
大步进主动缓启动，不能声称每个瞬态指标均改善。
