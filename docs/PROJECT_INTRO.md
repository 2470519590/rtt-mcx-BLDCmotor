# 【2026嵌入式大赛】轻量神经网络增强的智能无刷电机控制器——基于RT-Thread与NXP MCXA346

## 项目介绍

本项目基于NXP FRDM-MCXA346开发板与RT-Thread实时操作系统，设计了一套面向小型无刷电机的智能控制实验平台。系统将传统FOC控制与轻量神经网络残差补偿相结合，在保留传统控制基线的同时，探索数据驱动方法在低速运行、速度切换和周期性扰动补偿中的应用。

硬件采用2804无刷电机、AS5600磁编码器与SimpleFOC Mini驱动板。MCXA346负责角度采集、速度估计、三相PWM输出和闭环控制；PC通过外置USB串口模块与开发板通信。网页上位机用于直观观察电机角度、旋转状态和实时遥测，调参、校准及控制命令通过独立串口CLI完成。

## 主要功能

- **实时电机控制**：基于RT-Thread组织控制与通信任务，实现AS5600角度采集、速度估计、速度闭环和位置控制，控制任务目标周期为2 ms。
- **传统与学习控制并存**：保留速度前馈和PI控制基线，支持轻量神经网络影子推理与可切换的残差叠加，便于在同一平台上进行对照验证。
- **轻量部署流程**：在PC端完成数据采集、训练与权重导出，在MCU端使用C语言完成小规模网络推理，无需将模型运行依赖放入固件。
- **可视化监测**：网页提供自选串口、连续旋转仪表、机械角度、角速度及链路统计；网页不参与MCU闭环计算，也不负责电机启动。
- **实验可复现**：保留串口原始记录、模型文件、分析脚本和测试曲线，能够比较传统补偿、神经网络与简单线性方法的实际效果。

## RT-Thread与软件实现

软件分为MCU实时控制端和PC工具端。RT-Thread承担线程调度、时间基准和任务间状态同步：电机控制线程周期性完成传感器读取与控制计算，串口线程负责命令解析及遥测发送，UART接收中断与环形缓冲用于接收命令。上位机通过本地服务向浏览器推送最新状态，使显示刷新与实时闭环相互独立。

神经网络采用轻量残差增强思路，不直接替代传统控制器。系统既能只计算网络输出而不施加，也能在给定范围内叠加补偿；因此可以先检查模型输出与固件推理的一致性，再通过实板对照判断是否改善控制效果。

## 当前进展

目前已完成编码器读取、PWM驱动、速度与位置控制、串口CLI、网页监测及轻量网络训练部署通路。已完成多轮低速切换对照；其中25 ms的P项目标平滑在三轮、60段独立实板测试中，使整段RMSE均值下降约5.83%、首秒误差下降约11.77%。该项收益来自传统控制改进，不能算作神经网络收益。

神经网络通路已能够运行和验证，但尚未获得稳定超过简单线性预测的额外收益，后续将重点研究低速周期波动与角度相关扰动。当前硬件没有电流采样，采用电压模式FOC，不宣称具备闭环电流控制或量产级保护。
