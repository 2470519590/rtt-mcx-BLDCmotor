# 网页上位机视觉更新（2026-10-25）

## 范围

使用 `frontend-design` 技能确定仪表工作台布局与视觉层级；
安装了 `web-design-guidelines` 技能并检查键盘焦点、标签、响应式、
错误与空状态。其在线最新版规则获取失败，不声称完成了在线规则的全量审计。
两项技能安装在本机Codex skills目录，不打包进固件或参赛仓库。

设计采用深蓝#182d48、浅灰#f2f5f9、白色#ffffff、蓝色#285ee0、
橙色#df7a32和绿色#247456。桌面采用左仪表、右连接/数据的结构；
手机单列。使用本地系统字体，无CDN字体、外部图片或新增前端框架。
视觉重点是可连续转动的编码器仪表，其他区域保持简洁。

## 保留与调整

- 保留串口枚举/连接/断开、SSE最新状态推送、requestAnimationFrame显示。
- 保留角度、角速度、原始值、弧度与间隔显示；接收率与丢帧只是把既有统计
  从说明文字提取展示，没有新增硬件功能。
- 将USB VCOM旧提示改为外置USB–TTL；优先选中CH343但仍需用户点击连接。
- 不添加启动、校准、调参或NN控制面板，不调用`/api/control`。
  原后端断开串口时发S0的已有行为保持不变；因此“只读”指网页不启动/调参，
  不应解释为后端永远不向MCU写任何字节。
- 正负速度标注为编码器正向/反向，不假定物理观察视角的顺逆时针。
- 空状态不生成假数据，超时明确保留最后值；连接错误不会被刷新循环覆盖。
- SVG刻度、指针和转子为代码绘制，不需要图像生成服务。

## 运行

```powershell
conda activate py310
python tools/web_monitor.py
```

打开终端显示的本地地址。CLI先释放串口，网页再手动连接。
本轮验证不打开串口，不校准、烧录或启动电机。
