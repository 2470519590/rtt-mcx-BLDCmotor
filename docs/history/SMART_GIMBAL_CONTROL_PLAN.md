# NXP + RT-Thread + SimpleFOC Mini 智能电机控制系统计划书

## 1. 项目目标

基于 FRDM-MCXA346、RT-Thread、SimpleFOC Mini 三相驱动板和 2804 无刷电机，完成一个可调试、可闭环、可被上位机操作的单轴电机控制系统。第一阶段只做单电机闭环，后续再扩展为双轴云台。

目标控制链路：

```text
上位机
  ↓ USB Type-C / MCU-Link VCOM（LPUART2）
RT-Thread 控制任务
  ├─ AS5600 角度采样（LPI2C3）
  ├─ 位置/速度控制器
  └─ 三相 PWM 调制（FLEXPWM0）
       ↓
SimpleFOC Mini 栅极驱动/功率级
       ↓
2804 无刷电机
       ↑
AS5600 磁编码器
```

## 2. 最终硬件映射

### 2.1 调试、下载和上位机接口

取消云台电机协议使用的 LPUART3。项目只保留板载 USB Type-C 对应的 MCU-Link VCOM：

| 用途 | 外设 | 连接 |
|---|---|---|
| 下载、调试、上位机通信 | LPUART2 | 板载 USB Type-C |

LPUART3 的 `P4_2/P4_5` 不再初始化，也不再编译 `gimbal_uart.c`。USB Type-C 口仍承担固件下载、日志输出和上位机命令。

上位机通信建议先使用文本命令便于调试，稳定后切换为二进制帧：

```text
SET_MODE / SET_TARGET / SET_LIMIT / GET_STATE / STOP / CALIBRATE
```

### 2.2 AS5600 I²C

AS5600 使用 7 位 I²C 地址 `0x36`。角度采样优先读取：

| 信号 | MCU 引脚 | 板端 |
|---|---|---|
| SCL | `P3_27 / LPI2C3_SCL` | J5-5 |
| SDA | `P3_28 / LPI2C3_SDA` | J5-6 |

AS5600 关键寄存器：

| 寄存器 | 用途 |
|---:|---|
| `0x0B` | STATUS，检查磁铁检测状态 |
| `0x0C/0x0D` | RAW ANGLE，12 位原始角度 |
| `0x0E/0x0F` | ANGLE，经过配置的角度 |
| `0x1A` | AGC |
| `0x1B/0x1C` | MAGNITUDE |

第一版使用 `RAW ANGLE` 做软件零点和连续角度展开，不立即写入 AS5600 OTP。AS5600 的角度范围为单圈 0 到 4095，需要在 MCU 中处理 0/4095 跨越。

### 2.3 三相 PWM

SimpleFOC Mini 的三相输入固定为：

| 相位 | MCU 引脚 | PWM 通道 | 板上标注 |
|---|---|---|---|
| A | `P3_0` | `PWM0_A0` | `PWM_AT` |
| B | `P3_8` | `PWM0_A1` | `PWM_BT` |
| C | `P3_10` | `PWM0_A2` | `PWM_CT` |

外部连接关系为：

```text
P3_0  -> SimpleFOC Mini A / M1
P3_8  -> SimpleFOC Mini B / M2
P3_10 -> SimpleFOC Mini C / M3
```

这里的 `M1/M2/M3` 指 SimpleFOC Mini 功率级的三相输入，不是云台协议中的电机 ID。PWM 输出只能接驱动板逻辑输入，不能直接接 2804 电机绕组。

初始 PWM 参数：

```text
频率：20 kHz
逻辑电平：3.3 V
初始占空比：50% 或安全关闭态，按驱动板使能逻辑确定
```

必须确认 SimpleFOC Mini 的使能、故障、母线电压和输入逻辑电平定义。若驱动板需要独立 EN、FAULT 或刹车控制，应额外分配 GPIO。

## 3. 软件总体结构

```text
app/
  as5600.c/.h             AS5600 原始角度和状态读取
  board_i2c.c/.h          LPI2C3 阻塞传输底层
  simplefoc_pwm.c/.h      FLEXPWM0 三相输出
  motor_sensor.c/.h       角度归一化、零点、连续角度
  motor_control.c/.h      Clarke/Park 或简化电压调制控制
  motor_calibration.c/.h  相序、方向、零点和限位校准
  host_protocol.c/.h      USB VCOM 上位机协议
  control_task.c           RT-Thread 控制任务
```

RT-Thread 任务建议：

| 任务 | 周期/触发 | 责任 |
|---|---:|---|
| `motor_ctrl` | 1 kHz 起步 | 读取角度、计算控制量、更新 PWM |
| `sensor` | 1 kHz 或控制任务内同步 | AS5600 I²C 读取和连续角度展开 |
| `host_rx` | 事件/轮询 | 接收上位机命令 |
| `telemetry` | 20–100 Hz | 输出状态、故障和统计量 |
| `safety` | 1 kHz 或独立高优先级 | 超压、失联、角度异常、磁铁丢失和过流处理 |

第一版允许 `sensor` 与 `motor_ctrl` 合并，先保证时序可测；后续再拆分 DMA/中断和数据交换。

## 4. 控制策略分阶段实施

### 阶段 A：硬件和信号确认

1. 保留 LPUART2 USB VCOM，关闭 LPUART3。
2. 示波器确认三路 PWM 都为 20 kHz，初始占空比正确。
3. 断开电机，仅连接 AS5600，读取 `0x0B`、`0x0C/0x0D`、`0x1A`、`0x1B/0x1C`。
4. 手动转动磁铁，确认角度单调、跨越 0 点正确。
5. 确认 SimpleFOC Mini 的 EN/FAULT 和供电范围。

验收标准：无电机时，AS5600 能稳定输出角度；PWM 三路无明显抖动；USB VCOM 能持续打印日志。

### 阶段 B：开环低压试转

1. 电机安装 AS5600 磁铁，保证磁铁中心、气隙和同轴度。
2. 设置很小的电压幅值和较低电角速度。
3. 只允许短时间点动，默认带急停和 PWM 关闭。
4. 记录相序、转向、启动电流和异常声音。

这一阶段不闭位置环，重点是验证 `A/B/C` 相序、驱动板输入极性和电机连接。

### 阶段 C：位置传感器和零点校准

校准流程：

1. 检查 AS5600 磁铁状态 `MD/ML/MH`。
2. 读取静止角度作为机械零点候选。
3. 施加低幅值定向磁场，建立电角零点。
4. 记录方向符号和机械角到电角的映射。
5. 保存到 MCU Flash 配置区，不立即烧写 AS5600 OTP。

2804 只是电机外形规格，不能由型号直接确定极对数。必须根据具体电机 datasheet、齿槽/反电动势测试或低速校准确定极对数。

### 阶段 D：闭环控制

推荐顺序：

1. 角度读取闭环。
2. 速度估计和速度环。
3. 位置环。
4. 软限位、速度限幅、加速度限幅。
5. 加入云台姿态传感器后再做姿态外环和补偿。

第一版控制器建议使用确定性的 PI/PID，不直接上神经网络。神经网络应放在已有稳定控制器之后，用于摩擦、负载或振动补偿，并且必须有输出限幅和回退路径。

## 5. 关键参数待确认

以下参数不能仅由“2804”确定，实施前需要实测或查具体电机/驱动板资料：

- 电机极对数；
- 2804 绕组额定电压、电流和允许峰值电流；
- SimpleFOC Mini 的母线电压和电流能力；
- 驱动板是否带电流采样；
- PWM 输入是否需要互补输出或死区；
- EN、FAULT、BRAKE 的实际引脚和有效电平；
- AS5600 磁铁型号、尺寸、气隙和安装同轴度；
- 电机正方向和云台机械零位；
- 位置范围、最大速度、最大加速度；
- 上位机协议和遥测刷新率。

## 6. 安全策略

软件必须默认安全启动：

- 上电时 PWM 输出关闭或处于驱动板安全态；
- 未检测到 AS5600 磁铁时禁止闭环；
- AS5600 数据超时、跳变或磁场异常时立即降占空比并停机；
- 上位机失联超时后进入安全停机；
- 位置、速度、电压和电流均有硬限幅；
- 所有故障都能通过 USB VCOM 查询和清除；
- 机械调试阶段使用限流电源和可触发急停。

## 7. 代码实施顺序

1. 从 CMake 和 `rtthread_port.c` 移除 `gimbal_uart.c`、LPUART3 初始化和相关协议依赖。
2. 保留 `board_i2c.c`，增加 AS5600 驱动和角度读取接口。
3. 将 `simplefoc_pwm.c` 封装为 A/B/C 三相输出，并加入安全关闭接口。
4. 增加 AS5600 角度展开、零点和方向配置。
5. 增加 RT-Thread 电机控制任务。
6. 先实现开环点动，再实现角度闭环和速度限制。
7. 增加 USB VCOM 上位机命令和遥测。
8. 完成故障注入、断线、磁铁异常和超限测试。
9. 再扩展第二个轴、IMU 和云台姿态控制。

## 8. 第一版交付物

第一版完成后应具备：

- USB Type-C 下载和日志；
- AS5600 I²C 稳定读角；
- 三路 20 kHz PWM；
- 单电机开环点动；
- 单电机角度闭环；
- 软件零点和方向校准；
- 上位机设置目标角度、速度限制和停止命令；
- 状态、故障和角度遥测；
- 可复现的编译、下载和硬件验收步骤。

## 9. 当前决策

本项目不再使用云台原有的 LPUART3 电机协议作为控制主链路。控制主链路改为：

```text
LPUART2 USB VCOM
    +
LPI2C3 / AS5600
    +
FLEXPWM0 / SimpleFOC Mini
    +
2804 无刷电机
```

云台协议模块保留与否属于后续清理工作；正式实施时应从构建源文件和启动初始化中移除，避免未使用的 LPUART3 代码继续占用资源或误初始化引脚。
